# Quest 输入体验：当前开发范围

九键暂缓。本轮按顺序处理横屏弹出框、悬浮键盘、局域网跨屏输入。

## 已实现

- 跨屏输入弹窗宽度上限为 420dp，且不超过输入法窗口的 90%。
- 应用固定监听端口 8765；地址为 `http://Quest局域网IP:8765`。端口占用时提示错误，不自动更换端口。IP 仍可能因网络分配变化。
- 网页新增“断开连接”，停止该网页的同步、禁用编辑并清除内存中的连接状态；可再次点击连接。Quest 服务继续运行，其他网页不受影响。断开时已到达 Quest 的编辑不撤销，迟到的响应不会恢复网页连接。
- 横屏键盘默认高度由 85% 调整为 77%，为中文预编辑拼音行留出空间。手动保存的旧高度不会被覆盖。
- 普通尺寸泡泡截断已由用户确认修复。悬浮模式泡泡宽、高和字符面板单元格随键盘缩放。
- 悬浮键盘采用竖屏按键样式，包括边距、副字符位置等；拖动、缩放、恢复与位置保存继续保留。拖拽栏外观按用户要求暂缓。
- 跨屏输入使用四位数字配对码，连接的是输入法。网页自动跟随当前 Quest 输入框，清空和切换输入框不需要重新连接。
- 网页约每 200ms 同步文字和选区；中文输入法在组词结束后同步。Quest 上的文字、选区变化也会回读到网页。
- 使用 Android `getExtractedText` 回读完整文字，通过最小变更范围和 `setSelection` 更新内容与选区。应用拒绝回读、只提供片段、密码框或超出 32768 个 UTF-16 单元时，自动使用单向输入：网页新输入的文字自动发送后清空；提供退格按钮（空输入框也支持 Backspace）。单向模式不回读文字、不存储已输入内容、不控制选区。输入连接仍需支持提交文字或按键。网络错误时不自动重发单向操作，以免重复输入。
- 双向编辑发生冲突时采用最新 Quest 状态，自动更新网页，避免把旧输入框内容写入新输入框。单向模式直接向当前输入框提交文字或退格，不依赖回读版本，也不在提交前重置输入引擎，避免密码框重启产生误报 409。
- 服务使用明文 HTTP，适用于可信局域网。收起面板后继续运行，在跨屏输入面板显式关闭。连续五次配对错误后限流三十秒。

## 已确认的真机反馈

- 用户确认普通尺寸键盘的泡泡截断已修复。
- 用户反馈跨屏输入整体效果不错。
- 密码框单向输入的 409 修复后，用户确认测试通过。
- 拖拽栏外观优化继续暂缓；其余场景保留以下回归清单。

## 验证与操作约定

**调试包由用户统一安装、运行；代理只执行本地编译和测试，不安装或操作设备。**

本地构建：

```sh
./gradlew :app:assembleDebug -PbuildABI=arm64-v8a --offline
```

本轮回归测试：

```sh
./gradlew :app:testDebugUnitTest --tests '*CrossScreenServerTest' --tests '*TextChangeTest' --tests '*PopupPlacementTest' -PbuildABI=arm64-v8a --offline
```

已有测试问题：全量 JVM 测试中的 `ThemeSerializationTest.version2` 断言 2.0 数据无需迁移，但现有 serializer 已包含 2.1 候选栏颜色迁移；本轮没有修改主题代码与该测试。

设备测试曾被发起，但在本地 AndroidTest 资源链接阶段失败，缺少测试包的 `ic_launcher_debug`、`ic_launcher_round_debug`、`app_name_debug`，未执行到设备安装。弹出框定位回归现改为纯 JVM 测试。

网页逻辑回归（本地模拟 DOM 和服务状态，不代表 Quest 端到端验收）：

```sh
node app/src/test/js/cross-screen.test.cjs
```

## 真机验收清单

1. 横屏逐一长按顶部字母键，检查泡泡完整、多行字符可见、滑动高亮与实际选字一致。
2. 开启悬浮，移动到四角后长按按键；反复缩放，检查候选栏、符号页和工具栏；恢复后确认原尺寸，重启确认位置保存。
3. 同网设备填写四位配对码并点击“连接输入法”，收起 Quest 面板、选中目标输入框。网页输入中文、换行、Emoji，应自动同步，不再有发送按钮。
4. 两端分别插入、删除、清空文字、移动光标和选中文字；切换 Quest 输入框，网页应自动跟随且无需重新连接。
5. 网页中文组词过程中不应被轮询覆盖；暂时没有输入框时保持连接，重新选中输入框后恢复。
6. 应用不提供完整文字时，应进入单向输入；检查中文组词、插入和退格。Quest 的已有文字和选区不回传到网页。

调试包由用户统一运行；本轮只在本地编译与测试。
